# Relatório em PDF (Big Data)

`relatorio_big_data.pdf` é gerado por `gerar_pdf.py` na ordem exigida (01 a 09).
Cada print vem de `prints/`; o que ainda não existe sai como quadro tracejado com o nome esperado.
Para completar: salvar o print em `prints/<nome>.png` e rodar `python relatorio/gerar_pdf.py`
(precisa de `playwright` com Chromium).

Faltando: `r07_ouro_catalogo.png` (Catalog > workspace > gs), `r08_app_mvp.png` (tela do app),
`r09_github.png` (página do repositório).
